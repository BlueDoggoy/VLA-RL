# VLA-RL
Evaluating Residual Reinforcement Learning for Robust Household Manipulation

It's already established from this paper that residual RL can help a VLA model perform tasks more accurately. https://arxiv.org/pdf/2606.18953

They have already determined that for picking up a block etc, these tasks can be improved by a residual RL however we aim to diagnose when these tasks can fail and under what circumstances
